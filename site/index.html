uya-agent

一个 8.98 MB 的静态二进制，
就是整个编程 agent

给它一句话，它自己读文件、改文件、跑命令，多轮循环到给出结论。 全屏 TUI、浏览器界面、内核沙箱、自带 TLS —— 全在那一个文件里。 

curl -fsSL https://raw.githubusercontent.com/uya-lang/uya-agent/main/install.sh | sh
~/.local/bin/uya-agent --tui-demo

x86-64 Linux · 静态链接 · MIT · 零外部运行时

看一眼界面

它凭什么是一个文件

不是把东西打包进一个文件，是根本不需要别的东西。

8.98 MB、静态链接
没有 PT_INTERP、没有 NEEDED （make link-audit 每次构建都核）； 拷到没有编译器的机器上就能跑。
自包含工具链
uya/ 里带编译器与标准库（2.4 MB）， make build 不需要先装任何东西。
零外部运行时
不引 xterm.js、不走 CDN、不装 zlib —— 浏览器界面的终端解释器与 JPEG 编码器都是本仓自己写的。
离线可证
104 处断言、35 个 make e2e-*、内置 mock LLM： make selftest 全程不联网。

这不是炫技，是三个约束一路推下来的结果：

  1. 没有 libc 的通用设施 → TLS、OpenAI 两种线协议、SSE、YAML、diff、 markdown 全自己实现（src/net/ 9.8k 行、 src/diff/ 2.2k 行）。
  2. 不能引 xterm.js → 浏览器界面里的终端解释器写在服务端 （src/web/ttyemu.uya）。
  3. 没有 zlib → 图片缩放只能自己写；PNG / GIF / WebP 只能说「不支持」， 而不是「静默坏掉」。

能力一览

  • 全屏 TUI 常驻状态区、思考实时行、统计行（ctx / cpu / 内存）、任务块、 /diff 浮窗与 markdown 渲染；放不下的文本滚动显示。
  • web 界面（--web） 顶栏列会话标题，标题下就是该会话的真 TTY；页面零外部依赖， 终端解释器跑在服务端。
  • 三级访问模式 + bwrap 沙箱 read-only / workspace-write / danger-full-access 三档； workspace-write 下每次调用问你一次，并套 bwrap 内核沙箱。
  • 子代理与 ralph 子代理一族（含 ralph 与 /watch 实时跟随）， 也可以让 .ush 脚本编排一整轮 workflow。
  • Git worktree 每个会话在自己的 worktree 与分支里干活，做完提交、合并、删除， 连带残留回收 —— 出厂就是开着的。
  • 会话落盘可恢复 --continue / --resume / /sessions， 上下文自动剪枝与压缩。
  • 项目记忆 跨会话记住这个项目怎么跑、关键文件在哪、上次什么还红着， 按仓库根归类，开工时注入一条独立消息。
  • 纯 Uya src/ 下 182 个文件、15.2 万行，没有一个 @c_import。

它是什么语言写的

src/ 下 182 个文件、15.2 万行全是 Uya 源码， 没有一个 @c_import。 唯一的 C 是 src/cshim/ 那 840 行 —— 一段 Windows 控制台桥（make windows 才用到）和一份给 GCC 15 补的 C 原型头； Linux 产物不含任何本仓写的 C 逻辑。

Uya 编译到 C，再交给宿主的 cc 链接；仓库里已经带好了编译器 与标准库，所以从源码构建也只需要一个 C 编译器，不需要先装 Uya， 更不需要联网。

快速开始

1 · release 里的单个二进制

install.sh 只做三件事：判断架构、下载二进制、 chmod。不写配置、不改 PATH、不装运行时。

curl -fsSL https://raw.githubusercontent.com/uya-lang/uya-agent/main/install.sh | sh
~/.local/bin/uya-agent "把 hello.uya 的问候语改成 Hello, uya!"

2 · Docker

镜像是 FROM scratch：里面只有一个二进制， 没有基础发行版、没有 glibc、没有 shell。

docker build -t uya-agent .
docker run -it --rm -e DEEPSEEK_API_KEY -v "$PWD:/work" uya-agent

3 · 从源码

仓库自带编译器与标准库，make build 不需要预装任何东西， 也不需要联网。

git clone https://github.com/uya-lang/uya-agent.git
cd uya-agent
make build          # 产出 build/uya-agent（静态链接）
make selftest       # 离线端到端自测：内置 mock LLM，不要网络也不要 key
