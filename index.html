uya-agent

一个静态链接的编程 agent

给它一句话，它自己读文件、改文件、跑命令，循环到给出结论。 界面、沙箱、TLS 都在一个二进制里，拷到 x86-64 Linux 上就能跑。 

curl -fsSL https://raw.githubusercontent.com/uya-lang/uya-agent/main/install.sh | sh
~/.local/bin/uya-agent --tui-demo

v0.1.1 · 9.3 MB · 无 PT_INTERP、无 NEEDED · MIT

一个文件里有什么

体积 9,291,192 字节（9.3 MB / 8.9 MiB）
动态依赖 没有。PT_INTERP 0 条，NEEDED 0 条， make link-audit 每次构建都核
自带工具链 uya/bin 2.5 MB + uya/stdlib 2.7 MB，只要一个 C 编译器
离线自测 36 个 make e2e-*，--selftest 全程不联网

所以 TLS、SSE、YAML、diff、markdown 都是自己写的 （src/net/ 9.8k 行，src/diff/ 2.2k 行）。 浏览器界面的终端解释器也在服务端 —— 不引 xterm.js，自测才能离线。

能做什么

  • 终端界面 状态区、推理行、任务块、/diff 浮窗、markdown 渲染
  • 浏览器界面 每个会话一个标签，标题下就是它的真 TTY，不引外部资源
  • 三级访问模式 read-only / workspace-write / danger-full-access，后者不加沙箱
  • 子代理 并行委派、ralph 循环、/watch 跟读
  • Git worktree 每个会话一个分支，做完合并删除，默认开着
  • 会话与记忆 落盘可恢复，跨会话记住项目怎么跑，上下文自动压缩

和 dsh 比

第三方基准 OpenBench，四个任务，两臂同一模型 （deepseek-v4.1-flash，effort max，输出上限都 256000）， 各跑三次，串行。下面每个数都是这次跑出来的，不是引用旧记录。

中位数taskflow make-ci-greenadd-feature webcore
本仓 轮数 21101164
dsh 轮数 1861114
本仓 token 533k106k131k3,384k
dsh token 911k65k150k554k
本仓 耗时 86 s50 s134 s1372 s
dsh 耗时 279 s32 s175 s419 s

解出数：本仓 12/12，dsh 11/12（webcore 有一格停在基线 0.3）。 所以「都比 dsh 差」不成立 —— 四题两侧都解得出来。

差的是效率，而且方向按题而分：

  • webcore 本仓慢 dsh 14 轮 / 554k token / 419 s，本仓 64 轮 / 3,384k / 1372 s。 这是这次差距最大的一项，dsh 省 6 倍 token、快 3 倍。
  • taskflow 本仓更快更省 dsh 轮数少 3 轮，token 却是本仓的 1.7 倍（911k 对 533k）， 耗时 279 s 对 86 s。
  • make-ci-green dsh 全面占优 6 轮 / 65k / 32 s，本仓 10 轮 / 106k / 50 s。
  • add-feature 基本打平 都是 11 轮，token 131k 对 150k，耗时 134 s 对 175 s。

一句话：能力上没差，效率上本仓在 webcore（多模块、 要读大量代码）明显吃亏，在 taskflow 上反过来省 token。

n=3，报方向不报显著性。两臂都走同一条真路线（opencode zen）， 装置在 testdata/openbench_adapters/， 结果文件 results_final.jsonl（本仓）与 results_dsh_fixed.jsonl（dsh）。 dsh 的会话日志不写 reasoning token，那一列没比。 复现见 openbench_adapters/README.md。

快速开始

curl -fsSL https://raw.githubusercontent.com/uya-lang/uya-agent/main/install.sh | sh
~/.local/bin/uya-agent "把 hello.uya 的问候语改成 Hello, uya!"

或者从源码构建，仓库自带编译器，不需要联网： 

git clone https://github.com/uya-lang/uya-agent.git && cd uya-agent
make build      # 静态链接
make selftest   # 离线，不要 key

Docker 镜像是 FROM scratch，里面只有一个二进制。 

docker build -t uya-agent .
docker run -it --rm -e DEEPSEEK_API_KEY -v "$PWD:/work" uya-agent

已知限制

  • web 界面没有认证也没有 HTTPS 默认只绑 127.0.0.1
  • 终端解释器是白名单实现 只解这个 TUI 会发的序列，通用全屏程序显示不对
  • markdown 是子集 没有语法高亮、引用式链接、HTML 块、脚注
  • 只有 Linux 和 Windows 没有 macOS 构建

用什么写的

src/ 参与构建 183 个文件、152,730 行，全是 Uya， 没有一个 @c_import。其中自测占 35%， 生产代码 128 个文件、99,589 行。唯一的 C 是 src/cshim/ 那 840 行，只用于 Windows 控制台桥。
